# libs

Jars the build compiles against. They are not stored in the repository, put them here before building:

| File | Where to get it |
| --- | --- |
| `VulkanMod-0.6.8+1.21.11.jar` | [VulkanMod on Modrinth](https://modrinth.com/mod/vulkanmod) or [GitHub](https://github.com/xCollateral/VulkanMod) — use the same jar you play with |
| `modmenu-17.0.0.jar` | [Mod Menu on Modrinth](https://modrinth.com/mod/modmenu) |

If your file names differ, change them in `build.gradle`.
